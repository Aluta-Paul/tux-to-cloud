# tux-to-cloud

I'm learning Linux administration in public, with one goal: become a cloud engineer.

No bootcamp, no shortcuts. Just a home lab, a lot of `man` pages, and notes I write
down so I actually remember them.

## Why this repo exists

Two reasons.

1. Writing things down is how I learn. If I can't explain it in a note, I don't know it.
2. I want an honest record of the work. Not a polished portfolio — a trail of commits.

If you're also starting out, feel free to read along, steal the structure, or correct
me in an issue. I'm a beginner. Corrections are welcome and expected.

## Where I'm at

Starting from the basics. Linux first, cloud later. In that order, on purpose.

Right now: getting comfortable on the command line, understanding the filesystem,
users and permissions, processes, and basic networking.

Next: Bash scripting. Then a cloud platform. Then infrastructure as code.

I'm not skipping steps. The cloud runs on Linux. If I don't understand the machine,
The only rule have fun even when you cannot sleep.

## How I work

1. Pick one small thing to learn.
2. Do it on a real server or VM. Break it. Fix it.
3. Write it down in a note. Commands, what happened, what confused me.
4. Commit. Push. Move on.

Small commits, some honest notes, probably shared every week. That's the whole method.
